Quase isso! Você compreendeu muito bem a lógica, mas vamos ajustar os termos exatos para você dominar o comando.
Aqui está o que cada parte significa exatamente no PowerShell:
• New-Item: É a ação. Significa "Criar um novo item" (pode ser uma pasta ou um arquivo).
• -ItemType: É o parâmetro que pergunta "Que tipo de item você quer criar?".
• Directory: É a resposta para o tipo de item. Significa "Uma Pasta" (Diretório). Se você quisesse criar um arquivo, usaria File.
• -Path: É o parâmetro que diz "Em qual caminho/local?".
• "interface", "engine"...: São os nomes das pastas que você está criando. Como você não digitou um caminho completo (como C:\Users\...), o PowerShell cria essas pastas diretamente dentro do local onde ele está aberto (que no seu caso é a pasta do seu projeto no VS Code).
