# 🗄️ IA Vault - Guia de Armazenamento Frio Preventivo

Este documento é o inventário e manual de instrução para o ecossistema de Inteligências Artificiais armazenado localmente neste SSD externo. Toda a seleção foi otimizada para rodar de forma 100% offline em um setup com **RTX 3060 (12GB VRAM)** e **32GB de RAM**.

---

## ⚙️ 1. Kit de Ferramentas Offline (Executáveis)

Arquivos essenciais para reviver os modelos em qualquer máquina Linux sem dependência de internet ou servidores externos.

*   **Ollama para Linux (Binário Bruto):** [ollama-linux-amd64.tgz](https://ollama.com)
    *   *Uso:* Permite gerenciar e subir APIs locais facilmente.
*   **Llama.cpp (Executável Compilado):** [GitHub Releases](https://github.com)
    *   *Uso:* O motor bruto em C/C++. Garante que você consiga rodar qualquer arquivo `.gguf` direto pelo terminal se o Ollama deixar de existir. Baixe a versão `llama-bXXXX-bin-ubuntu-x64.zip`.

## 🚀 3. Instruções de Inicialização Rápida (Totalmente Offline)

Caso precise rodar um modelo diretamente do SSD sem instalar nada no sistema operacional do computador, use os seguintes comandos no terminal Linux:

### Iniciar uma conversa direta no terminal (Exemplo com Llama 3.1):
```bash
./llama-cli -m ../🧠_modelos_gerais/llama-3.1-8b-instruct-Q5_K_M.gguf -ngl 32 -p "Como posso ajudar você hoje?"
```

### Subir uma API local compatível com extensões de código (Exemplo com Qwen Coder):
```bash
./llama-server -m ../💻_modelos_codigo/qwen-2.5-coder-7b-instruct-Q5_K_M.gguf -ngl 32 --port 8080
```
*Nota: O parâmetro `-ngl 32` instrui o motor a enviar as camadas do modelo diretamente para a memória VRAM da placa de vídeo dedicada.*
